# @apisurf/ngn-core

Task compilation, scheduling, and the run/log/timing services that back the `ngn` CLI.

Part of [ngn](https://github.com/apisurf/ngn), a CLI scheduler for Node tasks.
It is published on its own so anything else can embed the runtime, but most people want the
[`@apisurf/ngn`](https://www.npmjs.com/package/@apisurf/ngn) CLI instead.

```bash
npm install @apisurf/ngn-core
```

ESM only. Versioned in lockstep with `@apisurf/ngn`.
